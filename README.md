# Каталог услуг: Telegram-бот

Бот-каталог объявлений об услугах: мастера, репетиторы, переводчики и другие специалисты.
Люди ищут услуги по категориям и размещают свои объявления, а администратор проверяет их
перед публикацией.

Написан на Python 3.11+ и [aiogram 3](https://docs.aiogram.dev/). Данные хранятся в SQLite.

## Что умеет бот

Интерфейс рассчитан на людей с плохим зрением: крупные кнопки, короткие тексты, без набора
команд.

- **Главное меню:** четыре большие кнопки внизу экрана, всегда на виду: «🔎 Найти услугу»,
  «➕ Разместить услугу», «📋 Мои объявления», «ℹ️ Помощь». В меню команд Telegram есть
  «Меню» и «Отмена».
- **Найти услугу:** категории и объявления кнопками по одной в ряд (подпись до 40 символов),
  по 8 объявлений на странице. Карточка короткая: название и цена в первой строке, всего
  не больше 5 строк. Под ней «Написать», «Пожаловаться» и «Назад».
- **Разместить услугу:** по одному короткому вопросу на шаг (категория, название, описание до
  300 символов, цена, район или город, телефон по желанию), предпросмотр и «Опубликовать».
  Внизу на всё время диалога две кнопки: «⬅️ Назад» (к предыдущему вопросу) и «❌ Отмена».
  Команда `/cancel` тоже отменяет диалог.
- **Мои объявления:** статус, «Скрыть», «Показать», «Удалить» (с подтверждением). Не больше 3
  объявлений на человека (на проверке и опубликованных).
- **Администратор:** `/admin` (статистика и очередь на проверке), `/delete НОМЕР`
  (удалить объявление), кнопки «Одобрить» и «Отклонить», жалобы пользователей.

## Как получить токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и адрес бота (адрес заканчивается на `bot`).
3. BotFather пришлёт токен вида `123456:ABC...`. Это пароль от бота: никому его не показывайте
   и не публикуйте.

Свой Telegram ID (нужен для администратора) можно узнать у бота
[@userinfobot](https://t.me/userinfobot).

## Как запустить

```bash
# 1. Установить библиотеки
python -m pip install -r requirements.txt

# 2. Создать файл настроек и заполнить его
copy .env.example .env      # в Linux и macOS: cp .env.example .env

# 3. Запустить бота
python -m bot.main
```

Настройки в файле `.env` (файл не попадает в git):

| Переменная     | Что это                                                              |
| -------------- | -------------------------------------------------------------------- |
| `BOT_TOKEN`    | Токен от BotFather                                                   |
| `ADMIN_IDS`    | Telegram ID администраторов через запятую, например `123456,789012`  |
| `DB_PATH`      | Путь к файлу базы SQLite, по умолчанию `data/bot.db`                 |
| `AUTO_APPROVE` | `1`: объявления публикуются сразу; `0`: сначала проверка администратором |
| `WEBAPP_URL`   | Публичный HTTPS-адрес Mini App (необязательно, см. раздел «Mini App»)  |
| `PORT`         | Порт сервера Mini App, по умолчанию `8000`                           |

Администратор должен хотя бы раз нажать `/start` у бота, иначе Telegram не даст боту написать
ему первым.

## Как добавить или изменить категорию

Откройте `bot/categories.py` и правьте список `CATEGORIES`. Каждая строка состоит из значка,
ключа и названия:

```python
Category("🎨", "design", "Дизайн"),
```

- **Ключ** пишите латиницей без пробелов и не меняйте после запуска: по нему объявления связаны
  с категорией. Если ключ изменить, старые объявления потеряют категорию.
- **Название** можно менять свободно.
- После правки перезапустите бота.

## Как работает модерация

1. Человек нажимает «Опубликовать». Объявление получает статус **«на проверке»** и не видно
   в каталоге.
2. Всем администраторам из `ADMIN_IDS` приходит карточка с кнопками **«Одобрить»**
   и **«Отклонить»**.
3. После нажатия автору приходит уведомление о решении. Одобренное объявление появляется
   в каталоге, отклонённое остаётся в «Моих объявлениях» со статусом «отклонено».
4. Если решение уже принял другой администратор, остальные увидят «уже обработано».
5. Очередь можно посмотреть в `/admin`, кнопка «На проверке».

Чтобы отключить проверку, поставьте `AUTO_APPROVE=1`: объявления будут публиковаться сразу.

Жалобы: кнопка «Пожаловаться» под карточкой отправляет жалобу всем администраторам. От одного
человека на одно объявление принимается одна жалоба. Нарушающее объявление удаляется командой
`/delete НОМЕР`.

## Mini App: каталог внутри Telegram

Кроме бота есть веб-приложение (Mini App): оно открывается внутри Telegram и показывает тот же
каталог в виде страницы. Бот остаётся запасным входом и присылает уведомления. Приложение и бот
используют одну базу и одни правила проверки.

Что умеет страница: каталог с поиском и плитками категорий, список и карточка объявления
(«Написать автору» открывает чат, «Пожаловаться»), размещение в 5 шагов с предпросмотром, «Мои
объявления» (скрыть, показать, удалить) и помощь. Нижнее меню: Каталог, Разместить, Мои, Помощь.
Дизайн для людей с плохим зрением: текст не мельче 19 пикселей, подписи не мельче 17, кнопки не ниже
56, контраст текста не ниже 4,5:1, значки только SVG.

### Как запустить

Нужны два процесса, они работают одновременно (в двух окнах терминала):

```bash
python -m bot.main       # бот
python -m webapp.main    # сервер Mini App, по умолчанию на порту 8000
```

Telegram открывает Mini App только по **HTTPS-адресу из интернета**, а сервер слушает только свой
компьютер (`127.0.0.1`). Мост между ними делает туннель.

### Временный HTTPS-адрес для проверки с телефона

Самый простой способ: Cloudflare Tunnel (бесплатно, без регистрации).

1. Скачайте `cloudflared` для Windows со страницы
   [github.com/cloudflare/cloudflared/releases](https://github.com/cloudflare/cloudflared/releases)
   (файл `cloudflared-windows-amd64.exe`) и положите его в отдельную папку **вне** проекта.
2. Запустите сервер (`python -m webapp.main`), а в другом окне туннель:

   ```bash
   cloudflared-windows-amd64.exe tunnel --url http://localhost:8000
   ```

3. В выводе появится адрес вида `https://что-то-случайное.trycloudflare.com`. Впишите его в `.env`:

   ```
   WEBAPP_URL=https://что-то-случайное.trycloudflare.com
   ```

4. Перезапустите бота (`python -m bot.main`). В меню появится кнопка «🌐 Открыть каталог», а рядом
   с полем ввода кнопка меню «Каталог».

Адрес меняется при каждом запуске туннеля: тогда нужно заново вписать его в `.env` и перезапустить
бота. Для постоянной работы нужен свой домен или хостинг с HTTPS; кроме `WEBAPP_URL` ничего
менять не придётся. Пока туннель открыт, страница доступна из интернета всем, у кого есть адрес, но
данные отдаются только после проверки подписи Telegram (см. ниже).

### Безопасность

- Telegram передаёт приложению строку `initData`, подписанную токеном бота. Сервер проверяет подпись
  (HMAC-SHA256, сравнение `compare_digest`) и срок: не старше 24 часов. Номер пользователя берётся
  **только** из проверенной строки, из запроса никогда.
- Права на «мои объявления», «скрыть», «показать» и «удалить» проверяются на сервере. Чужое
  объявление отвечает «не найдено», как будто его нет.
- Новое объявление не может задать себе статус или автора: лишние поля в запросе отклоняются.
- Проверка длины и содержимого полей общая с ботом (`bot/validators.py`), лимит объявлений тоже.
- Не больше 30 запросов в минуту на человека (счётчик в памяти).
- Текст объявлений выводится на странице через `textContent`, а не как HTML. Заголовки безопасности
  (`Content-Security-Policy` и другие) включены, страницы документации API отключены.
- В логи не пишутся токен, `initData` и тексты объявлений (журнал запросов отключён).
- Единственное место проверки доступа: `is_member()` в `webapp/auth.py`. Сейчас оно пропускает всех;
  позже сюда подключается закрытый доступ по коду приглашения.

### Методы API (для справки)

| Метод | Адрес | Что делает |
| ----- | ----- | ---------- |
| GET | `/api/categories` | Список категорий (без проверки пользователя) |
| GET | `/api/listings?category=&q=&page=` | Список опубликованных объявлений |
| GET | `/api/listings/{id}` | Одно опубликованное объявление |
| POST | `/api/listings` | Новое объявление (на проверку, администраторам уходит уведомление) |
| POST | `/api/listings/{id}/report` | Жалоба администраторам |
| GET | `/api/my/listings` | Мои объявления со статусом |
| POST | `/api/my/listings/{id}/hide` и `/show` | Скрыть и показать своё объявление |
| DELETE | `/api/my/listings/{id}` | Удалить своё объявление |

Все методы, кроме `/api/categories`, требуют заголовок `Authorization: tma <initData>`.

## Структура проекта

```
bot/
  main.py         запуск бота
  config.py       настройки из .env и константы (размер страницы, лимит объявлений)
  categories.py   список категорий
  db.py           работа с базой SQLite
  texts.py        все тексты и подписи кнопок
  keyboards.py    нижнее меню и кнопки под сообщениями
  validators.py   проверка ввода
  notify.py       сообщения администраторам и авторам
  handlers/       меню, поиск, размещение, мои объявления, жалобы, админка
webapp/           Mini App
  main.py         запуск сервера (FastAPI и uvicorn)
  auth.py         проверка подписи initData, is_member(), лимит запросов
  api.py          методы API и права
  schemas.py      проверка данных запросов и вид ответов
  static/         страница: index.html, css/ (переменные, основа, компоненты), js/ (api, screens, ...)
tests/            тесты базы, ввода, настроек, интерфейса бота, API и страницы Mini App
```

## Как изменить внешний вид

- Тексты и подписи кнопок: `bot/texts.py`.
- Размер страницы списка и лимит объявлений на человека: `PAGE_SIZE` и `MAX_LIVE_ADS`
  в `bot/config.py`.
- Длины полей объявления (название, описание и другие): `bot/validators.py`.
- Нижние кнопки по умолчанию высокие. Если они занимают слишком много места на экране, в
  `bot/keyboards.py` добавьте `resize_keyboard=True` в `main_menu` и `dialog_nav`.

Весь текст от пользователей выводится с экранированием HTML, поэтому разметку сообщений
сломать нельзя.
